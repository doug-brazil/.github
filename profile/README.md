# DOUG BR — DevOps User Group Brazil

**Unidos pela transformação.**

Somos uma comunidade brasileira que conecta quem trabalha, ou quer trabalhar, com DevOps, SRE e Cloud. Conteúdo gratuito, em português, feito por quem vive isso no dia a dia, do primeiro emprego à liderança técnica.

[Site](https://dougbrazil.tech) · [Eventos](https://dougbrazil.tech/eventos/) · [Blog](https://dougbrazil.tech/blog/) · [Vagas](https://dougbrazil.tech/vagas/) · [Manifesto](https://dougbrazil.tech/manifesto/)

## Nossos pilares

| | |
|---|---|
| **Conexão** | Meetups, encontros com outras comunidades e uma rede de gente que troca experiência de verdade |
| **Conhecimento** | Talks, artigos e workshops baseados em problemas reais, não em slide de marketing |
| **Acessibilidade** | Tudo gratuito, com linguagem acolhedora. Ninguém fica pra trás, inclusive quem está mudando de carreira |

## Como participar

- **Vá a um meetup.** A agenda fica em [dougbrazil.tech/eventos](https://dougbrazil.tech/eventos/), e os anúncios saem primeiro no [LinkedIn](https://www.linkedin.com/company/dougbrazil/).
- **Escreva no blog.** O conteúdo do site é aberto: posts, eventos e vagas entram por pull request no [dougbrazil-blog-content](https://github.com/doug-brazil/dougbrazil-blog-content). O README de lá explica o passo a passo, do frontmatter ao PR.
- **Divulgue uma vaga.** Vagas de DevOps, SRE, Cloud e Plataforma também entram pelo mesmo repositório.
- **Proponha uma talk.** Tem uma história de produção para contar? Fale com a gente pelo LinkedIn.
